# Тихий ритм — мобильная версия

Один редактор на JavaScript для **Android, iOS и браузера**. Весь код находится в `mobile`. Устанавливаемые версии собираются через Capacitor: интерфейс, примеры, звук и экспорт встроены в приложение. Сервер, работающий компьютер и интернет при запуске им не нужны, в том числе при первом открытии.

## Установить на Android

Готовая тестовая сборка: `mobile/releases/quiet-rhythm-android.apk`.

1. Перенесите APK на телефон: кабелем, через «Файлы» или отправьте себе файл.
2. Откройте APK на телефоне. При запросе разрешите установку для приложения, из которого открываете файл, и нажмите «Установить».
3. Откройте «Тихий ритм» с иконки. Можно сразу включить авиарежим: создание, изменение, прослушивание и экспорт не требуют сети.

Нужен Android 7 или новее с современным Android System WebView. В экспорте «Сохранить PNG» и «Сохранить табулатуру · JSON» открывают системный выбор папки. «Резервная копия» сохраняет всю библиотеку. Для офлайн-сохранения выбирайте папку телефона; облачные провайдеры в системном окне могут требовать сеть.

APK подписан отладочным ключом для прямой установки и проверки; публикации в Google Play ещё нет. Библиотека браузерной версии автоматически в приложение не переносится: сохраните резервную копию в браузере и откройте её в приложении. Удаление приложения или очистка его данных удаляет локальные работы.

## Установить на iPhone

Подготовлен проект `mobile/ios/App/App.xcodeproj` для **iOS/iPadOS 15.4 и новее** с тем же редактором, встроенными ресурсами и сохранением через «Файлы». **Готового IPA пока нет.** Если у вас Windows, используйте [инструкцию Codemagic → Sideloadly](native/CODEMAGIC-WINDOWS.md): сборка выполняется на облачном Mac, подпись и установка — через Sideloadly на Windows. Настройки сборки и чистый пакет исходников уже подготовлены. Бесплатная подпись требует обновления каждые 7 дней. APK на iPhone не устанавливается.

Пошаговая инструкция для сборки, проверки на своём iPhone и распространения: [native/IOS-INSTALL.md](native/IOS-INSTALL.md). После установки интернет для редактора не нужен. Временные тестовые подписи Apple имеют срок действия; они не заменяют постоянный выпуск приложения.

## Пересобрать установочные версии

Для разработки нужны Node.js 22+ и зависимости из lock-файла:

```sh
npm ci
npm run sync:native
```

Android в PowerShell:

```powershell
.\scripts\build-android.ps1
```

Скрипт требует JDK 21 и Android SDK Platform 36; Android Studio для запуска уже готового APK не нужен. Скрипт использует локальные инструменты в `artifacts/tooling`, если они есть, или пути `JAVA_HOME` / `ANDROID_HOME`. Собирает debug APK в `releases`, не меняет глобальные настройки среды. Для магазина нужен отдельный приватный release-ключ.

`npm run build:native` создаёт `native-dist` и копирует исходники небольших плагинов сохранения из `native` в проекты. `cap sync` встраивает ресурсы в обе платформы. Не добавляйте `server.url` в `capacitor.config.json`: сборка намеренно отклоняет удалённый адрес. Изменения редактора общие для всех версий.

## Дополнительная версия в браузере

Веб-версия сохранена для предварительного просмотра и PWA. Следующие команды относятся к её разработке; для использования установленного APK их запускать не нужно.

## Запуск на компьютере

В Windows откройте `run.bat`: запустится локальный сервер и откроется браузер. Окно сервера оставьте открытым.

Или в терминале из папки `mobile`:

```sh
npm start
```

Откройте `http://127.0.0.1:8787/`. `npm install` не требуется. Для другого порта: `npm start -- --port 8788`. Остановка — `Ctrl+C` в терминале. Открытие `index.html` двойным щелчком не заменяет HTTP-сервер.

## Проверка на телефоне

Подключите телефон и компьютер к одной Wi-Fi-сети. Запустите:

```sh
npm start -- --host 0.0.0.0
```

Откройте на телефоне `http://IP-КОМПЬЮТЕРА:8787/` (IPv4 компьютера можно посмотреть командой `ipconfig`). Если соединение блокируется, разрешите Node.js доступ к частной сети в брандмауэре Windows.

Этот HTTP-адрес подходит для проверки интерфейса, ввода и PNG. Для установки PWA и офлайн-режима на телефоне нужен **HTTPS**. Исключение `localhost` действует только на том устройстве, где открыт браузер.

## HTTPS и установка

```sh
npm run build
```

В `mobile/dist` появятся только статические файлы приложения. Разместите содержимое этой папки на HTTPS-хостинге и откройте полученную ссылку на телефоне. Скрипт обновляет только известные файлы сборки, не очищая папку рекурсивно; для публикации используйте отдельную папку `dist` без личных файлов.

- Android: меню браузера → «Установить приложение» или «Добавить на главный экран».
- iPhone: Safari → «Поделиться» → «На экран Домой».
- Для работы без интернета дождитесь статуса «Готово без интернета» в библиотеке.

После изменения кода увеличивайте версию кеша в `sw.js`. Новая версия начнёт работать после закрытия всех окон старого приложения. Во время разработки можно удалить регистрацию Service Worker в инструментах браузера; очистка данных сайта также удалит сохранённые работы.

## Что доступно

- Библиотека, поиск, создание, копирование и удаление табулатур.
- Ввод нот и аккордов крупными кнопками, паузы, автопереход, отмена и повтор.
- Одна партия или R/L, размер, темп, деления и слоги отдельных долей; счёт, коннакол и гибрид.
- Операции с тактами, прослушивание, повтор и метроном.
- Импорт JSON/TXT и резервной копии библиотеки. Совместимые JSON `hang-tab` версии 1 открываются из веб-версии Hang Creator.
- PNG всего произведения или выбранного такта, несколько изображений для длинных работ; JSON для дальнейшего редактирования. «Поделиться» появляется, когда браузер поддерживает отправку файлов.
- Длинный экспорт выдаётся порциями до восьми PNG: сохраните текущую часть и нажмите «Следующие изображения». Это ограничивает расход памяти телефона.
- Автосохранение в IndexedDB на этом устройстве; автономная работа после загрузки ресурсов по HTTPS или localhost.

«Резервная копия» сохраняет библиотеку в JSON. Очистка данных сайта может удалить локальные работы; автоматической синхронизации между устройствами нет. Разные адреса сайта имеют отдельные библиотеки. Прослушивание рассчитано на открытое приложение.

## Проверки

```sh
npm test
```

Проверка редактора, настоящего PNG и автономной перезагрузки веб-версии:

```sh
python tests/browser_smoke.py
python tests/browser_native_ui.py
```

Для этого сценария нужен Python 3 и Chromium (путь можно задать через `BROWSER_BIN`). Он использует временный профиль браузера и не меняет вашу библиотеку. Скриншоты и результаты появляются в `mobile/artifacts`.

Проверки библиотеки используют настоящий Chromium/Chrome/Edge. Если браузер не найден автоматически, укажите путь к нему переменной `BROWSER_BIN`. `browser_native_ui.py` проверяет интерфейс с подменёнными системными окнами; это не эмулятор Android/iOS. Проверка в браузере компьютера не заменяет проверку на реальном Android и iPhone; сохранение файлов, системное «Поделиться» и звук нужно проверить на выбранных телефонах.
