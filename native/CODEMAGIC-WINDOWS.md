# iPhone без Mac: Codemagic → IPA → Sideloadly на Windows

Codemagic работает в браузере. Скачивать и устанавливать его на компьютер не нужно: он собирает приложение на своём Mac. На Windows потребуется Sideloadly, чтобы подписать полученный файл вашим Apple Account и установить его на iPhone.

Этот путь предназначен для личной проверки приложения. С бесплатным Apple Account подпись действует **7 дней**. Затем её нужно обновить через Sideloadly; повторная сборка в Codemagic нужна только при изменении исходников. Редактор работает офлайн, но установка и обновление подписи требуют подключения к Apple. Это не бессрочная установка приложения из App Store. [Условия Sideloadly](https://sideloadly.io/).

## Что уже подготовлено

- `codemagic.yaml`: один ручной сценарий `ios-unsigned`, название **iPhone — IPA for Sideloadly**.
- `scripts/build-ios-unsigned.sh`: устанавливает зависимости, встраивает редактор и ресурсы, собирает приложение для физического iPhone и упаковывает IPA.
- Проект iOS с общей схемой App, иконкой, экраном запуска, локальным хранением и экспортом через «Файлы».
- Чистый пакет `releases/quiet-rhythm-codemagic-source.zip` и такая же папка `releases/codemagic-upload/` для загрузки исходников.

В пакете нет установленных зависимостей, служебной истории проекта или ключей подписи. `codemagic.yaml` находится сразу в корне. **Облачная сборка и установка на iPhone ещё не выполнялись; готового IPA пока нет.** Конфигурация проверена локально, включая формат YAML, Bash и схему Xcode.

## 1. Загрузить подготовленный проект в GitHub

Ваш существующий аккаунт GitHub подходит. Git и GitHub Desktop для этого способа устанавливать не требуется.

1. Откройте [создание репозитория](https://github.com/new).
2. Задайте имя, например `quiet-rhythm-mobile`, и доступ **Private**.
3. Оставьте автоматическое добавление README, `.gitignore` и лицензии выключенным. Нажмите **Create repository**.
4. На странице пустого репозитория нажмите **uploading an existing file**. Если в нём уже есть файлы: **Add file → Upload files**.
5. В Проводнике откройте `releases\codemagic-upload`. Либо распакуйте `quiet-rhythm-codemagic-source.zip` в отдельную папку и откройте её.
6. Выделите **содержимое** подготовленной папки: файлы и вложенные каталоги. Перетащите всё в область загрузки GitHub, дождитесь завершения и сохраните через **Commit changes**. Используйте Chrome или Edge, чтобы перетаскивать каталоги с сохранением структуры.
7. Проверьте результат: при открытии репозитория сразу видны `codemagic.yaml`, `package.json`, `package-lock.json`, каталоги `ios`, `native`, `scripts`.

Загружать сам ZIP, внешнюю папку `codemagic-upload` или весь каталог `исходный проект` не нужно: Codemagic должен видеть файлы проекта в корне репозитория. [Загрузка файлов и папок через браузер — GitHub](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).

## 2. Подключить GitHub к Codemagic

1. Откройте [codemagic.io](https://codemagic.io/) и зарегистрируйтесь либо войдите. Если предлагается вход через GitHub, используйте свой аккаунт.
2. Для личной проверки выберите личный аккаунт / **Individual**. На момент подготовки инструкции он включает 500 минут сборки macOS M2 в месяц. Условия и остаток минут проверяйте в кабинете; платный командный тариф для этого сценария не требуется. [Тарифы Codemagic](https://codemagic.io/pricing/).
3. Нажмите **Add application**, выберите **GitHub**.
4. Если появится **Next: Authorize integration**, разрешите подключение **Codemagic CI/CD**.
5. При **Install GitHub App** выберите свой GitHub-аккаунт, **Only select repositories** и только `quiet-rhythm-mobile`. Подтвердите **Install & Authorize**. Слово Install здесь означает подключение к GitHub; программа на Windows не устанавливается.
6. Выберите репозиторий. Если запрашивается тип проекта — **Ionic / Capacitor**, а при отсутствии такого пункта **Other** с настройкой через `codemagic.yaml`. Нажмите **Finish: Add application**.

Готовый файл `codemagic.yaml` уже задаёт команды и окружение. Для этого сценария не нужны Apple Developer Program, сертификаты, API-ключи App Store Connect или настройка TestFlight. [Подключение репозитория — Codemagic](https://docs.codemagic.io/getting-started/adding-apps/).

## 3. Собрать и скачать IPA

1. В Codemagic откройте добавленное приложение и нажмите **Start new build**.
2. Выберите ветку с загруженными файлами, обычно `main`.
3. Выберите workflow **iPhone — IPA for Sideloadly** (`ios-unsigned`) и запустите сборку.
4. Дождитесь результата **Finished / Successful**. Очередь и первая загрузка зависимостей могут занять время; закрывать браузер можно.
5. В результатах сборки откройте **Artifacts** и скачайте на Windows **`quiet-rhythm-ios-unsigned.ipa`**. Рядом будет файл `.sha256` с контрольной суммой; устанавливать его не нужно.

`unsigned` означает, что файл ещё не подписан вашим Apple Account. Следующий шаг выполняет подпись и установку. Простое открытие этого IPA в «Файлах» на iPhone приложение не установит.

Сценарий собирает вариант для физического устройства (`iPhoneOS`, `arm64`), проверяет встроенные ресурсы и структуру IPA. Он не отправляет приложение в магазин. При ошибке сборки сохраните текст неуспешного этапа или скачайте `build.log` / `xcodebuild.log` из артефактов: по ним можно исправить конкретную причину. [Сборка Capacitor в Codemagic](https://docs.codemagic.io/yaml-quick-start/building-an-ionic-app/).

## 4. Установить Sideloadly и подключить телефон

1. На Windows откройте [официальный сайт Sideloadly](https://sideloadly.io/) и выберите загрузку **Windows**; для обычной 64-битной Windows — 64-bit.
2. Перед установкой выполните требования раздела **Before you install**: Sideloadly нужны версии **iTunes и iCloud с сайта Apple**, ссылки **Web iTunes 64-bit** и **Web iCloud** приведены там же. Если уже стоят варианты из Microsoft Store, сначала замените их согласно этой инструкции. Не устанавливайте второй комплект поверх первого.
3. Запустите установщик Sideloadly и завершите установку. Перезагрузите Windows, если это попросит установщик Apple.
4. Подключите iPhone USB-кабелем, разблокируйте его и подтвердите **«Доверять этому компьютеру»**. Телефон должен появиться в Sideloadly.

Для приложения нужен iPhone или iPad с iOS/iPadOS **15.4 или новее**. Компьютер и телефон должны иметь доступ к интернету во время первой установки и проверки подписи.

## 5. Установить приложение на iPhone

1. Перетащите скачанный **`quiet-rhythm-ios-unsigned.ipa`** в окно Sideloadly.
2. Выберите свой iPhone в списке устройств, укажите Apple Account в поле **Apple ID**, нажмите **Start**. Используйте обычный режим подписи через Apple ID, не режим простой установки уже подписанного файла.
3. Если программа запросит пароль и подтверждение входа, введите их самостоятельно. Пароли, коды подтверждения и ключи не нужно присылать в чат.
4. Дождитесь успешного завершения установки. На телефоне появится **«Тихий ритм»**.
5. При сообщении о недоверенном разработчике откройте **Настройки → Основные → VPN и управление устройством**, выберите профиль своего аккаунта и подтвердите доверие. Следуйте дополнительным запросам вашей версии iOS. [Помощь Sideloadly](https://sideloadly.io/faq).
6. На **iOS 16 и новее**, если требуется режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Включите его, перезагрузите телефон и подтвердите включение после перезапуска. Этот пункт может появиться после подключения телефона и попытки установки. [Инструкция Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device/).

Откройте приложение. Когда iOS разрешит запуск, отключите кабель, включите авиарежим и проверьте создание и изменение табулатуры, воспроизведение, повторное открытие сохранённой работы, экспорт PNG и JSON. Для офлайн-экспорта выбирайте **«На моём iPhone»**, а не iCloud Drive. Это также первая полноценная проверка работы именно на вашем устройстве.

## 6. Пользоваться и обновлять

Редактор не требует сервера, открытого Codemagic или работающего компьютера. Все табулатуры сохраняются на телефоне.

При бесплатном Apple Account до истечения 7 дней подключите телефон к Windows и повторите установку **того же IPA тем же аккаунтом**. Не удаляйте приложение перед обновлением подписи и не меняйте его идентификатор. В Sideloadly также есть автоматическое обновление: для него компьютер должен быть включён, программа запущена, а телефон доступен по USB или в той же Wi-Fi-сети. Оно не работает при постоянно выключенном компьютере. [Обновление подписи — Sideloadly](https://sideloadly.io/faq).

Перед обновлениями сохраняйте библиотеку через кнопку резервной копии JSON. Удаление приложения удаляет и локальные работы. Если меняется код редактора, обновите файлы в GitHub, повторите сборку в Codemagic и установите новый IPA с прежним аккаунтом и идентификатором.

Если нужна обычная установка другим людям без еженедельного обновления, следующий этап — Apple Developer Program и выпуск через App Store; сборку также можно выполнять в Codemagic без собственного Mac. TestFlight подходит для тестирования, но каждая его сборка ограничена 90 днями. [Apple Developer Program](https://developer.apple.com/programs/enroll/), [TestFlight](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/).

## Что можно поручить помощнику

Подготовка исходников, конфигурация сборки, проверка пакета и исправление ошибок уже доступны без ваших паролей. После подключения GitHub к чату и предоставления доступа к нужному репозиторию можно проверить, какие действия интеграция позволяет выполнить за вас. Одного наличия аккаунта GitHub недостаточно для доступа из чата.

Вход и подтверждения GitHub / Codemagic, вход в Apple Account, подключение кабеля и подтверждения на iPhone выполняете вы. Запуск облачной сборки пока не выполнен от вашего имени. Если используете ручной путь выше, начните с загрузки папки `releases/codemagic-upload` в новый приватный репозиторий.
